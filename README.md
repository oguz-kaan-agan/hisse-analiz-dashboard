# 📈 Hisse Senedi Teknik Analiz Dashboard

Finansal piyasaları aktif olarak takip ettiğim için geliştirdiğim bu araç, Yahoo Finance'den gerçek zamanlı veri çekerek hisse senetleri üzerinde basit teknik analiz yapıyor. RSI ve Moving Average hesaplıyor, al/sat sinyali üretiyor.

---

## Özellikler

- Gerçek zamanlı hisse senedi verisi
- Kullanıcı tanımlı RSI ve Moving Average periyotları
- Al / Sat / Nötr sinyali
- Fiyat + RSI grafiği
- Web tabanlı arayüz

---

## Kullanılan Teknolojiler

`Python` `Flask` `Pandas` `yfinance` `Matplotlib`

---

## Kurulum

pip install -r requirements.txt
python app.py

Tarayıcıda aç: http://127.0.0.1:5000

---

## Kullanım

1. Hisse adını gir (AAPL, TSLA, NVDA vb.)
2. RSI ve MA periyotlarını ayarla
3. Analiz Et butonuna bas
